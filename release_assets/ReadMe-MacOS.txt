EDOPal for macOS
Your unofficial companion for EDOPro.

Requires macOS 14.4 or later. The universal build targets Apple Silicon
and Intel Macs.

1. Double-click the downloaded ZIP in Finder to extract EDOPal.app.
2. Open EDOPal.app. If macOS blocks an app from an unidentified developer
   and you trust the copy from this project's Releases page, open System
   Settings > Privacy & Security and choose Open Anyway if offered.
3. Check the EDOPro folder shown in the window. Use Change folder to
   choose the game folder you play on.
4. Open HD Cards, choose My decks or Full library, then select
   Sync HD cards.

Close EDOPro before applying appearance or audio changes. Settings stay
in ~/Library/Application Support/EDOPro HD Sync.

Apple's first-launch help: https://support.apple.com/en-us/102445
Downloads: https://github.com/cntrl-alt-lenny/edopro-hd-cards/releases
