EDOPal for Windows
Your unofficial companion for EDOPro.

1. Right-click the downloaded ZIP and choose Extract All.
2. Open the extracted folder and double-click EDOPal.exe.
3. Check the game folder shown in EDOPal. Use Change folder to pick
   the ProjectIgnis folder you play on.
4. Open HD Cards, choose My decks or Full library, then select
   Sync HD cards.

If SmartScreen shows a warning and you trust the copy from this project's
Releases page, choose More info, then Run anyway if Windows offers it.

Close EDOPro before applying appearance or audio changes. Reopen the
game to load them.

Settings stay in your per-user EDOPro HD Sync folder. To update, get the
new ZIP and use the newly extracted app.
https://github.com/cntrl-alt-lenny/edopro-hd-cards/releases
