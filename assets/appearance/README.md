# Appearance assets

The four Monokai packs contain the skin XML, controls and full-resolution textures from the OLED Deck's EDOPro 41.0.2 installation. The Deck project used its Kyogre, moon, nebula and Dark Souls wallpaper collection. The wallpaper and card artwork retain their original ownership. Public redistribution permissions for those images have not been verified.

The shared pack includes the original Vortex and 1998 OCG sleeves, Inter Medium, the InterEDO font variant and the 24 Thonk effects derived from Kenney's Casino Audio, Interface Sounds and UI Audio (CC0). Inter's license accompanies the installed fonts. [Inter license](Inter-OFL.txt)

Each ZIP contains game-relative paths. The installer uses `duplicates.json` to recreate byte-identical files stored once per archive. Installing a skin copies its files and fonts before setting the three appearance keys in `config/system.conf`.

Menu, deck editor and duel field previews were captured in EDOPro 41.0.2. The optional turn-player highlight changes the active life-point bar and its outline. The normal preview uses the original skin settings.
